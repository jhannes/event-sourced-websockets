# Real time applications with Websockets: (JavaScript edition)

Your users expect and deserve applications that update automatically in real time without refreshing or polling. This
application is a demonstration of how to use Websockets to get this effect.

## Why - a demonstration application

This application is a simplified version of an incident management application that would be a part of the process for
example to public safety answering points. In this setting, several responders many be observing the same incident and
it imperative that they see each other's notes without delay.
